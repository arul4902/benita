## Tech Stack

- **Semantic HTML5**: Native `<dialog>` modals, Schema.org LocalBusiness JSON-LD markup.
- **Vanilla CSS3**: Bespoke editorial luxury design system (Deep Teal `#075D60`, Wine Burgundy `#76204F`, Champagne Gold `#C8A66A`, Warm Ivory `#FAF6ED`).
- **Vanilla JavaScript (ES6+)**: Zero framework bloat, fast load times, accessible DOM APIs.
- **Node.js**: HTTP server with Range Requests (`206 Partial Content`) for video streaming.

## Local Development

1. **Start the local server:**
   ```bash
   node server.js
   ```

2. **Open in your browser:**
   ```
   http://127.0.0.1:8080/
   ```

3. **Run automated browser verification tests:**
   ```bash
   node puppeteer_test.js
   node test_overlap.js
   ```
